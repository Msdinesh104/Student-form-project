# Student-form-project

# 🎓 Student Details Management System

A responsive **Student Details Management System** built using **HTML**, **Tailwind CSS**, and **JavaScript**.  
This simple web application allows users to **add**, **edit**, and **delete** student records dynamically without using a database.

---

## 🚀 Features

- 🧾 **Add Student** — Fill in the form to add a new student record dynamically.  
- ✏️ **Edit Student** — Modify existing student details directly in the table.  
- ❌ **Delete Student** — Remove any student entry with a single click.  
- 🎨 **Responsive Design** — Built with Tailwind CSS for clean visuals and mobile-friendly layout.  
- ⚡ **Instant Updates** — All interactions happen in real time using pure JavaScript.

---

## 🧠 Functionality Overview

| Action | Description |
|:-------|:-------------|
| **Add Student** | Adds a new student entry to the table with details like name, age, gender, course, and email. |
| **Edit Student** | Converts selected row cells into input fields for inline editing. |
| **Save Student** | Updates the table with edited information instantly. |
| **Delete Student** | Removes a record permanently from the table. |

---

## 🧰 Technologies Used

- **HTML5** – Structure  
- **Tailwind CSS** – Styling and layout  
- **JavaScript (ES6)** – Interactivity and dynamic data handling
